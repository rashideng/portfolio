# Farhan Rashid · Portfolio

Personal portfolio of Farhan Rashid, Mechatronics Engineer (Galle, Sri Lanka).
Automated container farms, vertical farm towers, LED grow lamps and IoT hardware.

The site is a single static page: `index.html` plus the `assets` folder. No build step.

## Publish on GitHub Pages

1. Create a public repository named `<your-username>.github.io`.
2. On the repository page, click **Add file → Upload files**, drag in `index.html`, `README.md` and the whole `assets` folder, then **Commit changes**.
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io`.

## Updating

Edit `index.html` (or replace a file in `assets`), then upload the changed file the same way. GitHub Pages republishes automatically.
